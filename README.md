# Piyush Kumar — The Series

A cinematic, engineering-focused portfolio for Piyush Kumar, an aspiring Computer Engineer from Patna, India. The site presents practical software prototypes in Android engineering, evidence-aware document retrieval, multilingual communication, and public-welfare scenario planning.

## Live website

After the GitHub Pages workflow completes, the website will be available at:

`https://piyush0059.github.io/piyush-the-series/`

## Portfolio highlights

- **Truth-Trace** — evidence-aware document assistant prototype using BM25, lightweight word/character-trigram retrieval, and Reciprocal Rank Fusion.
- **Bloom** — multilingual reflective conversation interface with safety boundaries.
- **CodeLens** — Android code explanation, debugging, and optimization aid for seven languages.
- **NagarTwin** — transparent fictional 12-zone scenario-planning simulator for heatwaves, heavy rainfall, and power outages.
- **Anha.ai** — multilingual translation project with an experimental interpreter workflow.
- **AI Resume Parser** — resume-to-structured-profile extraction prototype.

Project cards link back to their source repositories. Descriptions distinguish prototypes from validated or production systems.

## Stack

HTML, CSS, and vanilla JavaScript. No framework installation or build command is required; GitHub Pages serves the site as a static website.

## Deploy

Deployment is automated through GitHub Actions. Every push to `main` publishes the repository root to GitHub Pages. In repository settings, set **Settings → Pages → Build and deployment → Source → GitHub Actions** if Pages has not yet been enabled.

## Local preview

Open `index.html` directly in a browser. All core navigation and interactions run client-side.

## Accuracy and limitations

- Truth-Trace is an experimental prototype; its small demonstration suite and some formula-based indicators are not independent scientific validation.
- NagarTwin uses fictional scenario zones and assumptions. It is not an emergency, forecast, evacuation, or government system.
- Bloom is a supportive conversation interface, not therapy or an emergency service.
- Anha's interpreter workflow is experimental and requires device-level testing.
