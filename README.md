## About this portfolio

A cinematic, engineering-focused portfolio that documents projects, implementation choices, and limitations—not just a list of technologies. The visual style uses dramatic dark surfaces, crimson highlights, editorial typography, animated reveals, a profile selector, horizontal project rails, and interactive case-study dialogs.

**Live website:** <https://piyush0059.github.io/piyush-the-series/>

The website is static. It does not expose API keys or run the AI projects' backends; project cards link to each project's own repository.

## Run locally

1. Clone this repository.
2. Open `index.html` in a browser.

No package installation or build command is needed.

## Deployment

GitHub Actions deploys the root website to GitHub Pages when changes are pushed to `main`. The workflow is in `.github/workflows/deploy.yml`.

If publishing is not yet enabled for this repository, open **Settings → Pages** and select **GitHub Actions** as the build and deployment source.

## Honesty about prototype status

- **Truth-Trace** is an experimental prototype. Its small demonstration suite and some formula-based indicators are not independent scientific validation.
- **NagarTwin** uses fictional scenario zones and illustrative coefficients. It is not an emergency, forecast, evacuation, or government system.
- **Bloom** is a supportive conversation interface, not therapy or an emergency service.
- **Anha.ai**'s interpreter workflow is experimental and depends on device speech services and configuration.
- **CodeLens** provides AI-generated suggestions that require independent review and testing.
